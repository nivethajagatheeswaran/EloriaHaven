# EloriaHaven

EloriaHaven is an AI-powered mental wellness platform designed to provide emotional support, guided self-reflection, mood tracking, and calming therapeutic activities through a clean, minimal, and privacy-first experience.

## Current Version

v1.1 (In Development)

## Tech Stack

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- FastAPI
- MongoDB
- Groq API

## Features

- AI Chat (Eloria)
- Mood Check-in
- Journaling
- Weekly Statistics
- Monthly Statistics
- Adaptive Theme
